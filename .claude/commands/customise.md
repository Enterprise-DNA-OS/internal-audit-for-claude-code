# Customise

Read CLAUDE.md and the requested change. Export a private backup. Inspect the schema and the affected CLI, view, document and test. Write the next numbered migration, never change an applied one. Add the field or rule with appropriate constraints and update the commands that use it. Run migration, seed and npm test on disposable data. Apply to working records only within the authorised change. Update docs/compliance.md when a rule changes, distinguishing local policy from the source. Do not weaken independent review or invent compliance evidence. Commit on main. Never publish.
