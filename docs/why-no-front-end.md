# Views without a front end

The weekly view and review report are private, read-only HTML files. The documents are print-ready drafts. Describe a change to your agent, and it runs a documented command against the database. Screens do not change records.

A hosted application adds mobile capture, live collaboration, drag and drop, sign-in and granular access control. This local base does not provide those capabilities. Omni by Enterprise DNA can build the screens and connections your audit team needs into its Command Centre, with access designed for the people using it. The free base needs no browser application or third-party login to run.

Use /new-view to add a private report. Do not publish evidence, reports or exports on a public site. Files can contain confidential audit findings.
